# Network Diagrams

This directory contains editable draw.io source files and exported SVG versions of the network diagrams used throughout the documentation.

## Diagrams

- `physical-topology` - physical device connectivity
- `vlan-transport` - VLAN tagging, PVIDs, and switch-port roles
- `security-policy-matrix` - high-level inter-zone firewall policy
- `recovery-access-paths` - normal administration and break-glass recovery paths
- `wireless-ssid-vlan-flow` - SSID-to-VLAN mapping and wireless infrastructure roles

The `.drawio` files are the editable source files.

The `.svg` files are the rendered versions embedded in the documentation.
